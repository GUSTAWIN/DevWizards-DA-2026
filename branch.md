# Integração Contínua – HealthSync

**O que é Integração Contínua?**
Integração Contínua (CI) é uma prática de desenvolvimento ágil onde cada membro da equipe integra suas alterações ao repositório principal com frequência, permitindo detectar erros rapidamente e manter o projeto sempre funcional. No HealthSync, isso garante que funcionalidades como o registro de dados de saúde, o painel médico e o módulo comercial evoluam sem quebrar o que já foi entregue.

**Qual é o papel das branches nesse processo?**
As branches permitem que cada desenvolvedor trabalhe em uma funcionalidade isolada sem interferir no código principal. No HealthSync, cada atividade ou feature (ex: tela de dashboard, casos de uso, histórias de usuário) é desenvolvida em sua própria branch, mantendo a branch principal estável e sempre pronta para entrega.

**Por que o Pull Request é importante?**
O Pull Request é o momento de revisão antes de integrar o código à branch principal. Ele permite que a equipe avalie as mudanças, aponte melhorias e evite a entrada de erros no projeto. No HealthSync, o PR garante que qualquer novo módulo — seja do lado do paciente ou do módulo comercial — seja validado pelo grupo antes de ser mesclado.
